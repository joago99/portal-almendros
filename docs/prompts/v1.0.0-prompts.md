# Prompts — v1.0.0

## Resumen
Portal de clientes para Constructora Los Almendros: sistema PHP+SQLite con CRUD de proyectos, clientes, pagos, documentos y panel admin. Deploy en Hostinger + Cloudflare.

## Prompts usados (mejorados)

### Prompt 1: Correcciones portal clientes (8 funcionalidades)
**Versión mejorada:**
```
Corrige en el portal:
1. Proyectos: popup crear con nombre, solicitante, presupuesto modificable. Filtro por estado. Al hacer clic, detalle + edición. Contar documentos asociados.
2. Clientes: botón "Ver obras" abre popup con proyectos. Editar. Mostrar presupuesto aprobado y pago a la fecha.
3. Pagos: popup nuevo pago con proyecto, fecha, monto. Editar y cambiar estado.
4. Documentos: selección múltiple, borrar, filtrar por proyecto/cliente.
5. Admin: panel de usuarios, crear/asignar, cambiar contraseña.
```

### Prompt 2: Debug botones que no funcionan
**Versión mejorada:**
```
Los botones del portal no ejecutan nada. Causa raíz: los modales usan innerHTML con <script> tags que no se ejecutan. Solución: reemplazar scripts embebidos por onsubmit="return funcion(this)" y definir las funciones en el script global de cada vista. También el router .htrouter.php tenía rutas mal mapeadas y los backends solo leían $_GET['action'] pero los formularios enviaban POST.
```

### Prompt 3: Deploy a Hostinger
**Versión mejorada:**
```
Portal listo para producción. DNS en Cloudflare, hosting en Hostinger (PHP 8.3 + SQLite). Subir vía FTP, ejecutar setup.php y seed-users.php. Configurar subdominio portal.constructoralosalmendros.cl con registro A apuntando a IP del servidor. SSL con Cloudflare en modo Flexible.
```

### Prompt 4: Error 500 en create proyecto
**Versión mejorada:**
```
El create proyecto devuelve 500. Causa: la tabla projects no tiene columna address (setup.php antiguo). Solución: ALTER TABLE projects ADD COLUMN address. Además client_id es NOT NULL pero el form envía vacío → hacer client_id nullable.
```

## Lecciones aprendidas
- Los <script> dentro de innerHTML no se ejecutan → usar onsubmit/onclick con funciones globales
- El router debe estar sincronizado con la estructura real de archivos
- Las rutas de bases de datos SQLite en producción necesitan migraciones explícitas
- FTP con firewalls requiere modo pasivo y timeout largo
- Cloudflare proxy requiere SSL/TLS en modo Flexible cuando el origen no tiene SSL
